# Model/Data Provenance

Every generated dataset or model should record, where applicable:

- source identifier
- source URL/provider
- retrieval date
- provider/model name
- applicable license or terms
- whether content was synthetic
- generation configuration
- human-authored additions
- transformations
- filtering/validation
- training code revision
- base model and license
- model architecture
- training parameters
- hardware
- output hashes

This is an engineering provenance system, not a legal determination of ownership.
